# 🚶 How Walkable Is Dhaka City?

A GIS-based Walkability Index for Dhaka City developed using Python, GeoPandas, OSMnx, NetworkX, and Streamlit.

## 🌐 Live Dashboard

**[Open the Dhaka Walkability Dashboard](https://dhaka-city-walkability-dashboard-r8obqhgznysicma7jdebsj.streamlit.app/)**

## 📊 Project Overview

This project evaluates walkability across Dhaka City using a 500 × 500 m spatial grid and five key dimensions:

* Street Connectivity
* Essential Services
* Public Transport Accessibility
* Green Space Accessibility
* Network-based Walking Accessibility

Each grid cell receives an overall Walkability Score from **0–100** and is classified from **Very Poor** to **Excellent**.

## 🗺️ Key Features

* Interactive walkability map
* Component-level spatial analysis
* Top and bottom walkability areas
* Problem-zone identification
* Network-based accessibility analysis
* Interactive grid-cell diagnostics
* Streamlit dashboard

## 🛠️ Tools & Technologies

Python · GeoPandas · OSMnx · NetworkX · Pandas · Folium · Streamlit

## 📍 Study Area

Dhaka City, Bangladesh
